### M1-1 逐声明 × 逐属性的三分判定

对 v1 的**每条身份声明 × 每个属性**给出且只给出三种判定之一：

| 判定 | 定义 | 门槛 |
| --- | --- | --- |
| **可接地** | 读侧**已证实**能分出该属性值 | 该属性值在 ≥1 代归档的 ≥1 帧里被报出，且**该帧内无同名属性共现** |
| **超粒度** | 读侧在全部已证实证据里**从未**分出该属性值 | 全部归档的该通道全部帧都没有该值 |
| **条件可接地** | 依赖额外条件（视角、目标在特定区域、特定回合）才分得出 | 值出现过但只在**可陈述的子条件**下出现（条件必须写出来，不许写"有时可以"） |

每条**超粒度**判定必须带证据链：**哪一代归档、多少帧、读侧报了什么**（不是"试了一下没有"）。

### M1-2 逐 case 的"已证实判别力"档案

每个 case 一份，字段固定：

1. 实测颜色集合（读侧报出过的颜色名，逐代分列）；
2. 读侧形状词表（报出过的形状名，逐代分列）；
3. 每帧可见物体数分布（min / 中位 / max，逐代分列）；
4. **同名属性共现计数**（v0.6 B2 的 0 帧正式化为档案项，不是结论）；
5. 每件物体每集的 look 数实测（需求画像的原料，见 P3）。

### M1-3 措辞纪律

档案名为"**已证实**判别力"。M1 的输出里**不许出现**"传感器其实能分辨 X"这种句式；
有限帧证据给出的是下界，v2 只能在这个下界之内写声明。

### 判据修正 1（开跑后、写进读数之前；修正只削弱主张，不制造主张）

**首跑读到的东西**：v03/v04/v05/v06 四代相机归档**只跑过 c1 与 c3**（每格 2 case ×2 repeat），
c2/c4/c5/c6 **从未上过相机通道**。首跑按原判据把它们的全部属性判成"超粒度"，
而那**不是读侧的判别力读数，是没有证据**。原判据少了一个类别，缺口如下：

| 类别 | 定义 | 触发条件 |
| --- | --- | --- |
| **无已证实证据**（`no_confirmed_evidence`） | 该 case 在**全部**相机归档里**没有任何一帧** | 逐 case 逐通道的帧数为 0 |

修正理由（与读数无关，是逻辑缺口）：**没有证据不等于证据表明没有**。若不修，
v2 会把四个从未被传感器检验过的 case 的声明按"传感器做不到"删掉——
这是本阶段能犯的最贵的错，因为 v2 落地之后没人能再分辨一条声明是被检验过还是被漏掉的。

修正后的判定顺序（先判有没有证据，再判三种粒度）：

```
frames == 0                      -> no_confirmed_evidence
有帧 且 值从未出现                -> beyond_grain（超粒度）
有帧 且 值出现过 且 至少一帧无同名 -> groundable（可接地）
有帧 且 值出现过 但从不在首观测出现 -> conditionally_groundable（条件可接地，条件写出来）
```

**这一条修正只把一部分"超粒度"降级为"无证据"，不产生任何新的"超粒度"**——
方向上是削弱主张，因此不构成"看着结果改判据"。

### 判据修正 2（实现不符判据，按判据改实现，不是改判据）

首跑的第二版把"该值是否出现在集的首个观测里"混进了判定，于是把
**从未出现在首观测**的值标成 `conditionally_groundable`，条件句还自相矛盾
（写着"never"、同时打印"first-look hits: 6"）。核对 M1-1 的原文：
**可接地 = 报出过且该帧内无同名共现**，首个观测不在判定里。
于是改**实现**回到判据原文，并把"首观测看见几个物体"移到**判别力档案**里
（它是 #26 的签名，属于画像而不是判定）。
